### First-Person 3D Rewrite
**What:** Complete rewrite of game from 2D Canvas top-down shooter to first-person 3D flight simulator using Three.js (v0.170.0 via CDN importmap). Single `index.html` file, ~784 lines.
**Why:** Andrew requested a first-person flying simulator dogfight game. Started with PvE, carrying over all existing features refactored for 3D.
**Branch:** `first-person-3d`

Key architecture:
- Three.js WebGL renderer with shadows, ACES filmic tone mapping
- Shader-based sky dome with day/night blending
- Pointer lock API for mouse look
- Procedural 3D jet models (CylinderGeometry, ConeGeometry, ExtrudeGeometry)
- 3D particle system using THREE.Points with BufferGeometry
- 2D Canvas HUD overlay (cockpit frame, crosshair, speed/altitude tapes, enemy indicators)
- All audio functions carried over from original
- All game systems ported: waves, enemy AI (scout/fighter/bomber/ace/zombie/megabomber/boss), day/night cycle, powerups, scoring, combos, barrel rolls, takeoff sequence

Controls: Mouse look (pointer lock), WASD throttle/roll, left click gun, right click/F missile, Q/E barrel roll, P pause
